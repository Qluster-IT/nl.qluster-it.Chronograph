ОСОБЕННОСТИ

* Понятные карточки-потоки для легкой интеграции таймеров, секундомеров и переходов в вашу домашнюю автоматизацию.
* Создавайте таймеры, секундомеры и переходы напрямую из карточек-потоков, без необходимости предварительной настройки.
* Запускайте таймеры с длительностью в миллисекундах (доли секунд), секундах, минутах, часах или днях.
* Запускайте секундомеры без заранее определенного времени окончания.
* Запускайте переходы для постепенного изменения параметра устройства со временем.
* Запускайте потоки на точных продолжительностях таймера или секундомера с точностью до миллисекунды (доли секунд).
* Приостанавливайте и возобновляйте таймеры, секундомеры и переходы с помощью карточек действий или из настроек.
* Поддержка случайных или вычисленных длительностей или настроек с использованием простых математических выражений.
* Все таймеры, секундомеры и переходы сохраняются после перезапуска Homey.
* Указывайте несколько таймеров, секундомеров и переходов одновременно, используя подстановочные знаки в поддерживаемых карточках.
* В настройках виджета Chronograph на панели управления можно выбрать таймер, секундомер или переход, а затем приостановить, возобновить или остановить его.
* Используйте математические выражения внутри карточек-потоков.
* Используйте HomeyScript для отслеживания, приостановки, возобновления или остановки активных таймеров, секундомеров и переходов.

Карточки действий для запуска, возобновления и настройки включают поддержку простых математических выражений. Это позволяет задавать случайные или вычисленные длительности таймеров и секундомеров, включая расчеты на основе значений токенов.
Например:

	ceil(99.5) / 5
	pick(1, 3, 5, 9) * 2
	random(10, 30)
	abs(-10)

В дополнение к доступным карточкам-потокам, таймеры и секундомеры также могут управляться с помощью [HomeyScript](https://homeyscript.homey.app).

Например, этот скрипт остановит все запущенные таймеры:

	const app = await Homey.apps.getApp({ id: 'nl.fellownet.chronograph' });
	const timers = await app.get({ path: '/timers/' });
	for (const timer of timers) {
		if (timer.running) {
			await app.delete({ path: '/timers/' + encodeURIComponent(timer.name) });
		}
	}

Посетите тему на форуме сообщества для получения дополнительной информации!
