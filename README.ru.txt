ФУНКЦИИ

* Понятные карточки потоков для легкой интеграции таймеров, секундомеров и переходов в вашу домашнюю автоматизацию,
* Создание таймеров, секундомеров и переходов прямо из карточек потоков, не требуется предварительная настройка,
* Запуск таймеров с длительностью в миллисекундах (дробных секундах), секундах, минутах, часах или днях,
* Запуск секундомеров без заданного времени окончания,
* Запуск переходов для постепенного изменения параметров устройства с течением времени,
* Активируйте потоки в точный момент завершения таймера или секундомера с точностью до миллисекунд,
* Приостанавливайте и возобновляйте таймеры, секундомеры и переходы с помощью карт действий или непосредственно из настроек,
* Поддержка случайных или вычисленных длительностей или корректировок с использованием простых математических выражений,
* Все таймеры, секундомеры и переходы сохраняются даже после перезапуска Homey,
* Нацеливайтесь на несколько таймеров, секундомеров и переходов одновременно, используя подстановочные знаки в поддерживаемых картах.

ПРОСТЫЕ МАТЕМАТИЧЕСКИЕ ВЫРАЖЕНИЯ

Карточки действий для начала, возобновления и корректировки имеют встроенную поддержку простых математических выражений. Это позволяет задавать случайные или вычисленные длительности для таймеров и секундомеров, включая расчеты на основе значений токенов.

Например:

	ceil(99.5) / 5
	pick(1, 3, 5, 9) * 2
	random(10, 30)
	abs(-10)

Помимо основных математических выражений, поддерживаются следующие функции:

* abs(x) - вычисляет абсолютное значение числа,
* ceil(x) - округляет число вверх до ближайшего целого,
* floor(x) - округляет число вниз до ближайшего целого,
* round(x) - округляет число до ближайшего целого,
* random(min, max) - случайное число больше или равно min и меньше max,
* min(x, y) - наименьшее число из переданного списка,
* max(x, y) - наибольшее число из переданного списка,
* pick(x, y[, n]) - выбирает случайное значение из переданного списка.

HOMEYSCRIPT

Помимо доступных карточек потоков, таймеры и секундомеры также можно управлять с использованием [HomeyScript](https://homeyscript.homey.app).

Например, этот скрипт остановит все запущенные таймеры:

	let app = await Homey.apps.getApp({id:'nl.fellownet.chronograph'});
	app.apiGet('/timers').then(result => {
		let timers = JSON.parse(result);
		timers.forEach(timer => {
			app.apiDelete('/timers/' + timer.id);
		});
	});

* GET /timers - получить список всех активных таймеров,
* GET /timers/:id - получить один таймер,
* PUT /timers/:id - приостановить или возобновить таймер,
* DELETE /timers/:id - остановить таймер.
* GET /stopwatches - получить список всех активных секундомеров,
* GET /stopwatches/:id - получить один секундомер,
* PUT /stopwatches/:id - приостановить или возобновить секундомер,
* DELETE /stopwatches/:id - остановить секундомер.
* GET /transitions - получить список всех активных переходов,
* GET /transitions/:id - получить один переход,
* PUT /transitions/:id - приостановить или возобновить переход,
* DELETE /transitions/:id - остановить переход.
